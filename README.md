# 🦷 OdontoSys - Sistema de Gerenciamento Odontológico

## 📌 Sobre o projeto
O **OdontoSys** é um sistema desktop desenvolvido para auxiliar no gerenciamento de clínicas odontológicas, permitindo o controle de pacientes, consultas, tratamentos e informações clínicas.

Este projeto foi criado com o objetivo de praticar desenvolvimento em Java e organização de sistemas completos.

---

## 🚀 Tecnologias utilizadas
- Java
- JavaFX
- Banco de Dados
- Padrão MVC (Model, View, Controller)

---

## ⚙️ Funcionalidades
- Cadastro de pacientes
- Agendamento de consultas
- Gerenciamento de tratamentos
- Controle de funcionários
- Registro de pagamentos
- Odontograma (visualização dentária)
- Prontuário do paciente

---

## 🧠 Estrutura do projeto

- **model** → classes de dados  
- **dao** → acesso ao banco de dados  
- **controller** → lógica da aplicação  
- **view** → interface gráfica (JavaFX)
